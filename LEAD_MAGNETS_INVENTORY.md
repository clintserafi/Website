## Next Steps

### To Make These Downloadable on Your Site:

**Option 1: Host Files in Website Repo**
1. Create `/assets/lead-magnets/` folder in your website repo
2. Upload all .docx and .pdf files there
3. Update download links in `lead-magnets.html` to point to the files
4. Users can download directly from your site

**Option 2: Use Google Drive / Dropbox**
1. Create a shared folder for each resource
2. Get shareable links
3. Update download links in `lead-magnets.html` to point to Drive/Dropbox
4. Easy to update files without re-deploying website

**Option 3: Email Delivery (Gated)**
1. Add Formspree form on lead-magnets.html
2. On submission, email the files to the user
3. Build your email list
4. Can add to email automation sequence
